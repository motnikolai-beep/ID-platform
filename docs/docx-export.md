# Экспорт черновика в DOCX

Установите дополнительную зависимость в окружении приложения:

```sh
python -m pip install -r requirements-docx.txt
python SKRF_platform.py
```

Выберите форму, заполните объект и данные, нажмите «Экспорт черновика в DOCX».
Значения заново проверяются перед экспортом. Незаполненные поля допускаются
только как часть явно обозначенного черновика и перечисляются в файле.
Это универсальная таблица полей, не нормативный бланк АОСР.
Все выгрузки, включая approved-шаблоны, помечаются как черновики.

Файлы сохраняются в exports внутри каталога данных приложения:
по умолчанию .id-platform в домашней папке; переопределение через
ID_PLATFORM_DATA_DIR. Полный путь отображается в сообщении интерфейса.
Имя содержит UTC-время и UUID. Существующие файлы не перезаписываются.
Экспорт не сохраняет снимок в SQLite: для этого есть отдельная кнопка.

Экспорт предназначен для локального настольного запуска. Скачивание
из браузера, диалог выбора пути, подпись и нормативная вёрстка пока отсутствуют.
При отсутствии python-docx остальные функции остаются доступны; кнопка
экспорта показывает команду установки. SKRF.py не изменяется.

Проверены создание и повторное чтение DOCX, кириллица, пустые значения,
0 и False, маркировка черновика, уникальность имён и отказ при несовпадении
версий. Визуальный запуск Flet и пагинация в Word не проверены.
