# Новая версия

Запуск в существующем окружении Flet из корня проекта:

```sh
python SKRF_platform.py
```

Это новая реализация интерфейса, не полная копия SKRF.py. Оригинал сохранён.
Поиск требований пока доступен только в оригинальном приложении.

Включите показ непроверенных форм, выберите учебную карточку, заполните
поля, проверьте предзаполнение и сохраните снимок. Это не нормативная форма.
Проверенных форм, DOCX/XML, подписания и выпуска в этой версии нет.
Все поля интерфейса текстовые. Применимость по ОПО пока не реализована.

Каждое сохранение создаёт новый снимок проекта и черновика: значения,
версия и полный паспорт шаблона, результат проверки. Незаполненные поля
не препятствуют сохранению черновика. Снимки видны в истории всех объектов;
открытие снимка для редактирования и отдельный реестр проектов пока отсутствуют.
При закрытии окна несохранённые данные теряются.

База platform.db хранится в .id-platform домашней папки пользователя.
Путь можно переопределить переменной ID_PLATFORM_DATA_DIR.
База rt_cache.db не изменяется. Не добавляйте рабочую базу в Git.
Визуальный запуск и совместимость с установленной версией Flet не проверены.
